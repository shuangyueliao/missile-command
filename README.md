# Missile Command · 城市拦截防御

Free single-file HTML5 arcade defense game. Defend six cities from waves of
incoming warheads — launch interceptors from three silos, detonate shockwaves,
chain explosions for combo multipliers. One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/missile-command/

- Mouse / touch (tap anywhere to fire), procedural WebAudio sounds
- Neon vector visuals, MIRV splitters, wave bonuses, city rebuild every 2 waves
- Best score saved locally, no dependencies
