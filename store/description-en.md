# Missile Command — Store Submission Materials

## Short description (CrazyGames / GameDistribution / itch.io)

Defend six cities from waves of incoming warheads. Launch interceptors from
three silos, blast shockwaves, and chain explosions for combo multipliers.
How long can your cities survive?

## Details

- Genre: Arcade / Action / Defense
- Controls: Mouse / Touch (click or tap anywhere to launch an interceptor
  from the nearest armed silo). Keyboard: Space/Enter to start and continue,
  M to mute.
- Features: Wave-based defense (8+2×wave warheads per wave, faster each
  wave), MIRV split warheads from wave 2, chain-reaction shockwave combos
  (×1–×8), wave bonuses (+100 per surviving city, +5 per unused interceptor),
  a bonus city rebuilt every 2 waves, best-score saving, procedural graphics
  and sounds, single-file HTML5 (no external assets), works offline once
  loaded.
- Tech: Vanilla JavaScript, Canvas, WebAudio. No frameworks, no tracking.
